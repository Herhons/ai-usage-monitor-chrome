AI 用量配额监控

九家 AI 服务的额度用量，直接在浏览器工具栏查看。

开源 · MIT 许可证

关于

AI 用量监控是一个个人使用的 Manifest V3 Chrome 扩展，用来一眼查看 OpenCode、Claude、ChatGPT / Codex、GitHub Copilot、Google Gemini、Cursor、Perplexity、Mistral Le Chat 和 xAI Grok 的订阅额度用量。

在设置中只启用你订阅的服务商，未启用的会被隐藏。OpenCode 基于密钥：在设置里填入你的 Go 套餐 API Key。其余服务商复用浏览器里已有的登录态，这些会话 Cookie 不会被复制或存储。

用量数据直接从各服务商获取，不会离开你的电脑。无统计、无追踪、无自有服务器——纯本地。
